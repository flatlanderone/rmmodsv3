# Hotfix for the Revolver Magazine Size Issue - version 3.0.1.0

## Overview

This hotfix removes the MagazineSize stat from the magnitude stats block for gunHandgunT0PipePistol and gunHandgunT2Magnum44 in order to prevent the spawning of these weapons with 10-round magazines.

## Requirements

 - 7 Days to Die v3.0.

## Manual installation

 1. Download the mod file.
 2. Unzip it anywhere on your hard drive.
 3. Copy the **HotFixRevolverMagazineSizeFLTR** folder to the 7 Days to Die Mods folder. The default location is **%APPDATA%\7DaysToDie\Mods**. 
 4. If you are updating the mod, delete the folder with the old version.
